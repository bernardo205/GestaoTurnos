# Gestão de Turnos

A shift-management application built with **Python** and **Streamlit**, designed to record and review shifts and make basic statistics easier to explore.

## Features

- Register shifts.
- Browse shift history.
- Edit and delete existing records.
- View statistics and charts.

## Tech stack

- Python
- Streamlit
- pandas
- Plotly

## Run locally

1. Clone the repository and enter the project directory.
2. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

3. Start the application:

   ```bash
   streamlit run app.py
   ```

Streamlit will print the local URL where the application is available.
