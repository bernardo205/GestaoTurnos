# Gestão de Turnos

Aplicação de gestão de turnos desenvolvida em Python com Streamlit, utilizando SQLite para guardar os dados.

**Estado atual:** a aplicação só está a funcionar para **um funcionário**. O suporte a vários funcionários ainda não está implementado.

O projeto será recomeçado a partir de uma nova base, com os requisitos definidos antes do desenvolvimento das novas funcionalidades.

## Tecnologias

- Python
- Streamlit
- SQLite
- pandas
- Plotly

## Executar localmente

Instalar as dependências:

```bash
pip install -r requirements.txt
```

Iniciar a aplicação:

```bash
streamlit run app.py
```

> A descrição acima refere-se à aplicação existente. Não significa que as funcionalidades previstas para a nova versão já estejam implementadas.
